# ⚽ Pró-Atleta Android (APK via GitHub Actions)

Repositório configurado para compilar automaticamente o aplicativo Android **Pró-Atleta** na nuvem do GitHub e gerar o arquivo instalador **`.apk`**.

## Como baixar o APK gerado:
1. Clique na aba **Actions** no topo deste repositório no GitHub.
2. Clique no último workflow concluído (**Gerar APK Android (Pro-Atleta)**).
3. Role até o final da página na seção **Artifacts** e clique em **`ProAtleta-APK-Instalador`** para baixar o `.apk`.
